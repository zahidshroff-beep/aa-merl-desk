# IMP MERL desk — tester walk (country unit)

Altamont Advisory MERL desk. Any programme. Auto drafts from **that** programme’s documents. You Accept.

**Tester URL:** https://imp-preview-imp3.vercel.app

Work stays in your browser. This is not IMP production.

## What this walk is for

Country as the operating unit: ethics investigation, 48-hour requests to the country office, respondent frame that blocks KIIs.

Use a **live assignment**. The example is only if you have no TOR.

## Walk (~25 minutes)

1. **New programme.** Name, client, period, walk as yourself. Put the ICC name in ICC (default).
2. Paste TOR / proposal / logframe as **text** in Source documents. PDF must be pasted.
3. Purpose → ToC → Inception. Automate or do it yourself. Auto must not Accept. Empty Accept must refuse.
4. Inception: AA Accept, then client Accept with a letter or dated note, named. Field stays closed until both.
5. **Protocols / ethics (the new work).**
   - Automate. Sites must come in **Unknown**. Auto must not mark Cleared or Not required.
   - Try Cleared with no letter — must refuse.
   - Try Not required with “programme only” — must refuse. Confirmation must name the country-office person and cover the **evaluation**.
   - Heightened scrutiny (tick it) closes Not required.
   - Send a 48-hour request. ICC to focal point. No intermediary. Send without a focal point must refuse.
6. Accept ethics only when no country is still Unknown.
7. **Field.**
   - Add a respondent missing contact. Log a KII — must stay blocked.
   - Complete the row on a Cleared (letter) or legal Not-required site — then it can plan.
   - An Unknown / Required / In process site must refuse the event.

Do not score Design stages 3–8 or Evaluate stages 5–9. They are visible and locked.
